What success looks like

For a maintainer

  • You found your package and understand the band.
  • You can see which signals drove the result.
  • You know this is a triage aid, not a malware verdict.

For a security team

  • The action runs on a pull request without a local install.
  • The result appears as a focused comment or SARIF.
  • You can start advisory with fail-on: none.

Start advisory

The default CI example does not block merges. Raise the threshold only after reviewing the output for your repositories. 

- uses: ovidiurg/maintainerwatch@main
  with:
    index-url: https://github.com/ovidiurg/maintainerwatch/releases/latest/download/maintainerwatch-index.json
    base-ref: origin/${{ github.base_ref }}
    fail-on: none
    comment: "true"
    upload-sarif: "true"

Pin the action to a commit or release tag for production. Do not use pull_request_target for untrusted pull requests.
